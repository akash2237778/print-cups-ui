Choose your device

  1. Open Settings → Bluetooth & devices → Printers & scanners (Windows 10: Devices → Printers & scanners).
  2. Click Add device, wait a few seconds, then click Add manually (Windows 10: The printer that I want isn't listed).
  3. Choose Select a shared printer by name and paste a printer's Windows / Mac address from above (it starts with http://). Click Next.
  4. When Windows asks for a driver, pick Manufacturer Microsoft → Microsoft IPP Class Driver (older Windows: Microsoft PS Class Driver). Don't choose Generic / Text Only — it can only print plain text.
  5. Already added it with another driver? Open the printer → Printer properties → Advanced → Driver and pick Microsoft IPP Class Driver.
  6. Finish, then print a test page if you like.
  7. Make it the default: in Printers & scanners turn off Let Windows manage my default printer, open the printer and click Set as default.

iPhones only find printers on the same Wi-Fi, so we install a small settings profile that tells your phone where the office printers are. You do this once.

  1. Open this page in Safari (other browsers can't install profiles).
  2. ⬇ Download printer profile — tap Allow.
  3. Open the Settings app → tap Profile Downloaded near the top (or General → VPN & Device Management) → Install → enter your passcode → Install. It says “Unverified” because it's our own office profile — that's expected.
  4. To print: in any app tap Share (□↑) → Print → Printer and choose an office printer. Your iPhone remembers the last printer you used.
To remove it later: Settings → General → VPN & Device Management → Office printers → Remove Profile.

Android's built-in printing only finds printers on the same Wi-Fi. Two options:

  1. Easiest – QuickPrint as an app: open QuickPrint in Chrome → ⋮ → Add to Home screen. Print by opening it and choosing files (PDF, photos, screenshots).
  2. Print from any app: install a print plugin from the Play Store that lets you type a printer address, such as CUPS Printing or Let's Print Droid. Add a printer using the Android address from above (it starts with ipp://), then enable the plugin in Settings → Connected devices → Printing. It then appears under Share → Print in every app.
Android has no “default printer” setting — it shows the printer you used last.
